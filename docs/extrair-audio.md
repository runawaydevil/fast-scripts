# Extrair Áudio

Programa para tirar o áudio de vídeos, um de cada vez ou vários de uma pasta.

## Como abrir

Abra o arquivo `extrair-audio.cmd` na pasta `Vídeos` (duplo clique ou Execute).

Na primeira vez, se faltar algo necessário no computador, o programa avisa e mostra o que instalar. Depois de instalar, feche e abra de novo.

## Passo a passo

1. **Pasta ou vídeo**  
   Confirme o caminho sugerido (Enter) ou cole/digite uma pasta ou um arquivo de vídeo.

2. **Formato do áudio**  
   Escolha:
   - MP3 — compatível com tudo  
   - M4A — bom equilíbrio qualidade × tamanho  
   - WAV — sem compressão (arquivo maior)  

   Enter usa o formato padrão (o último usado, quando houver).

3. **Aguarde o processamento**  
   Cada vídeo é listado; arquivos que já existem no destino são ignorados.

4. **Resultado**  
   Os áudios ficam na pasta `Áudio`, dentro da pasta de origem. Subpastas são preservadas.

## Dicas

- O programa lembra a última pasta e o formato usados.
- Se um vídeo não tiver faixa de áudio, a extração pode falhar.
- Pressione Enter no final para fechar a janela.
