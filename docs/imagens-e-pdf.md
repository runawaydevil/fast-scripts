# Imagens e PDF

Programa para juntar imagens em um PDF, ou transformar páginas de PDF em imagens.

## Como abrir

Abra o arquivo `imagens-e-pdf.cmd` na pasta `Imagens` (duplo clique ou Execute).

Na primeira vez, se faltar algo necessário no computador, o programa avisa e mostra o que instalar. Depois de instalar, feche e abra de novo.

## O que escolher

1. **Imagens → PDF** — junta as imagens de uma pasta em um único PDF.
2. **PDF → Imagens** — salva cada página do PDF como imagem.

---

### Imagens → PDF

1. Cole o caminho da pasta com as imagens.
2. Confira quantas imagens foram encontradas (ordem alfabética).
3. Digite o nome do PDF (Enter = `saida.pdf`).
4. O arquivo é criado **dentro da mesma pasta**.

### PDF → Imagens

1. Cole o caminho de um PDF ou de uma pasta com PDFs.
2. Escolha o formato: PNG (Enter = padrão) ou JPG.
3. Informe a qualidade em DPI (Enter = 150; 300 = alta).
4. As imagens vão para uma pasta com o nome do PDF + `-imagens` (ex.: `documento-imagens`).

## Dicas

- Nas imagens → PDF, a ordem das páginas segue o nome dos arquivos (A–Z).
- Pressione Enter no final para fechar a janela.
