# Criar GIF / Slideshow

Programa para transformar vídeo em GIF, ou uma pasta de fotos em um vídeo (slideshow).

## Como abrir

Abra o arquivo `criar-gif.cmd` na pasta `Vídeos` (duplo clique ou Execute).

Na primeira vez, se faltar algo necessário no computador, o programa avisa e mostra o que instalar. Depois de instalar, feche e abra de novo.

## O que escolher

1. **Vídeo → GIF**
2. **Fotos (pasta) → vídeo (slideshow)**

---

### Vídeo → GIF

1. Cole o caminho de um vídeo ou de uma pasta com vídeos.
2. Informe a largura do GIF em pixels (Enter = 480).
3. Informe os quadros por segundo (Enter = 12).
4. Os GIFs ficam na pasta `GIF`, ao lado dos vídeos. Arquivos que já existem são ignorados.

### Fotos → slideshow

1. Cole o caminho da pasta com as fotos.
2. Informe quantos segundos cada foto aparece (Enter = 2).
3. Digite o nome do vídeo (Enter = `slideshow.mp4`).
4. O arquivo é criado **dentro da mesma pasta**. A ordem das fotos é alfabética.

## Dicas

- GIFs muito longos ou com muita resolução ficam grandes; use largura e FPS menores se precisar.
- Pressione Enter no final para fechar a janela.
