# Limpeza segura

Programa que limpa arquivos temporários do sistema e, se quiser, esvazia a Lixeira — sempre com prévia antes de apagar.

## Como abrir

Abra o arquivo `limpeza-segura.cmd` na pasta `Úteis` (duplo clique ou Execute).

## Passo a passo

1. Aguarde a análise. Nada é apagado ainda.
2. Veja a prévia: temporários do usuário, do Windows e cache de atualizações, com tamanho aproximado e total recuperável.
3. Confirme com `s` (ou `sim`) para limpar esses temporários. Qualquer outra resposta pula essa etapa. Arquivos em uso são pulados automaticamente.
4. Em seguida, o programa pergunta se quer **esvaziar a Lixeira** também (`s`/`sim` ou não).
5. Ao terminar, veja quanto espaço foi liberado (quando a limpeza rodou).

## Dicas

- A limpeza é só de pastas temporárias/cache listadas — não mexe em Documentos, Downloads, etc.
- Esvaziar a Lixeira é permanente; confirme só se tiver certeza.
- Pressione Enter no final para fechar a janela.
