# Organizar por tipo

Programa que separa os arquivos soltos de uma pasta em subpastas por categoria (imagens, vídeos, áudio, documentos, etc.).

## Como abrir

Abra o arquivo `organizar-por-tipo.cmd` na pasta `Organizar` (duplo clique ou Execute).

## Passo a passo

1. Cole o caminho da pasta a organizar.
2. Veja a prévia: quantos arquivos vão para cada categoria (Imagens, Vídeos, Áudio, Documentos, Compactados, Programas, Outros).
3. Confirme com `s` (ou `sim`) para mover. Qualquer outra resposta cancela.
4. Os arquivos são movidos para subpastas com esses nomes, **dentro da mesma pasta**. Se já existir um arquivo com o mesmo nome, um número é acrescentado.

## Dicas

- Só organiza arquivos **soltos** na pasta (não entra em subpastas já existentes).
- Confira a prévia antes de confirmar.
- Pressione Enter no final para fechar a janela.
