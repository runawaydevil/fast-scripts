# Analisar Espaço

Responde "o que está enchendo meu HD?" — mostra o espaço de cada unidade, as maiores subpastas e os maiores arquivos.

## Como abrir

Dê um duplo-clique em `Úteis\analisar-espaco.cmd` — ou abra o `canivete.cmd` na raiz e escolha pelo número.

## O que precisa

- Nenhum programa extra

## Passo a passo

1. Veja o **espaço de cada unidade** (aparece logo de cara).
2. Informe a **pasta** para analisar em detalhe.
3. Veja as maiores subpastas e os maiores arquivos.


## Onde salva

Nada é salvo — é só leitura.

## Dicas

- **Nada é alterado**: o programa só lê.
- Comece pela raiz da unidade (`C:\`) para achar o vilão, depois vá afunilando.
- Combina bem com o [achar-duplicados](achar-duplicados.md) e a [limpeza-segura](limpeza-segura.md).
